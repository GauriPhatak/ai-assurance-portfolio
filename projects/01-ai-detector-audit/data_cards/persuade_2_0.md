# Data card: PERSUADE 2.0

Reader: anyone using this corpus in the detector audit, including reviewers checking provenance.
Last checked: 2026-11-20.

## Summary

About 26,000 argumentative essays written by US students in grades 6 to 12, on 15 prompts across two tasks (independent and text dependent). Each writer has demographic fields, including English learner status and disability status. In this project it is the main source of human-written essays for comparing false positive rates between English learners and other students within a single corpus.

## Unit of observation and size

The CSVs have **one row per discourse element**, not per essay. Essay-level fields repeat on every row of the same essay.

| Split | Rows | Essays |
|---|---:|---:|
| train | 173,266 | 15,594 |
| test | 112,117 | 10,402 |
| **total** | 285,383 | **25,996** |

No essay appears in both splits. The train/test split comes from the Kaggle competition and has no meaning for this audit, so both splits are used.

## Fields used in the audit

| Field | Meaning | Values | Essays missing |
|---|---|---|---:|
| `essay_id_comp` | Essay key | 8 to 12 character IDs, unique | 0 |
| `full_text` | Essay text | never displayed or committed | |
| `prompt_name` | Prompt | 15 prompts | 0 |
| `task` | Writing task | Independent, Text dependent | 0 |
| `grade_level` | Grade | 6, 8, 9, 10, 11, 12 | 1,168 |
| `ell_status` | English learner | Yes, No | 1,301 |
| `student_disability_status` | Disability | Identified / Not identified as having disability | 5,173 |
| `economically_disadvantaged`, `race_ethnicity`, `gender` | Demographics | as recorded | see data |
| `provider` | Data provider (state or source) | Virginia, Indiana, Florida, NCES, Georgia Virtual | 0 |
| `holistic_essay_score` | Holistic score | 1 to 6 | 0 |

- **Disability status** means the student has an IEP or 504 plan. The source README states that no other information is available.
- Missing values are blank or a single space in the CSV. The counts table reports them as `Missing`.

Essay counts by prompt, grade, English learner status and disability status are in [`results/corpus_essay_counts_summary.md`](../results/corpus_essay_counts_summary.md) (marginals) and [`results/corpus_essay_counts.csv`](../results/corpus_essay_counts.csv) (full cross-tabulation, by split). Both are generated by `make counts`.

## Known issues

1. **`essay_id` is corrupted; use `essay_id_comp`.** 1,108 `essay_id` values have been converted to scientific notation (for example `5.04604E+12`), probably by a spreadsheet, and two of them now collide across different essays. `essay_id_comp` is unique, maps to exactly one `essay_id`, and gives the published total of 25,996 essays.
2. **Grade is missing for a whole prompt.** All 1,168 essays from the Georgia Virtual provider (the "Phones and driving" prompt) have no grade. Grade and prompt are therefore partly confounded.
3. **Missing demographics are not random.** English learner status is missing for 1,301 essays and disability status for 5,173. How missingness relates to provider and prompt should be checked before group comparisons.
4. **English learners are a small group.** 2,244 essays (about 9% of those with known status) are from English learners. This limits power for English learner comparisons, especially within prompt and grade. See the sampling plan.
5. **Small cells.** Many cells of the full cross-tabulation (prompt by grade by English learner status by disability status, by split) are small. The committed table suppresses any count below 11 essays, with complementary suppression so hidden counts cannot be recovered by subtraction. The rule is stated in the counts summary.

## How to obtain

```
make data          # downloads with gdown, verifies SHA-256, extracts the test zip
```

The test zip password is published in the source README (https://github.com/scrosseye/persuade_corpus_2.0#readme). It is not stored in this repo. Set `PERSUADE_TEST_ZIP_PASSWORD` in the environment or in an untracked `.env` file (see `.env.example`).

**Manual fallback** (if gdown is blocked, for example by a Google Drive quota): open the two Drive links above in a browser, save the files with the exact names shown into `data/raw/persuade_2_0/`, then run `make data-verify`. That checks each file's size and SHA-256 against the manifest before extracting, and prints the expected URL and path for any file that is missing or does not match.
