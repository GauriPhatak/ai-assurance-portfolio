# Data card: ELLIPSE

Reader: anyone using this corpus in the detector audit, including reviewers checking provenance.
Last checked: 2026-11-20.

This card covers two datasets from the same source:

1. **The final ELLIPSE corpus** (6,482 essays), used in the main analysis.
2. **The raw rater-scores file** (8,890 rated essays), **excluded from the main analysis**. See the last section.

## Summary

The English Language Learner Insight, Proficiency and Skills Evaluation (ELLIPSE) corpus contains essays by English language learners in grades 8 to 12, written during US state standardized annual testing. Each essay has a holistic proficiency score and six analytic scores (cohesion, syntax, vocabulary, phraseology, grammar, conventions). In this project it is a second source of human-written essays by English learners, used to check whether PERSUADE results hold in another corpus.

## Final corpus

### Unit of observation and size

One row per essay.

| Split | Essays |
|---|---:|
| train | 3,911 |
| test | 2,571 |
| **total** | **6,482** |

`text_id_kaggle` is unique within and across splits. Both splits are used; the split is a Kaggle artifact.

### Fields used in the audit

| Field | Meaning | Values |
|---|---|---|
| `text_id_kaggle` | Essay key | mostly 12 character hex IDs (22 have other lengths, see known issues) |
| `full_text` | Essay text | never displayed or committed |
| `prompt` | Prompt | 44 prompts |
| `task` | Writing task | Independent only |
| `grade` | Grade | 8, 9, 10, 11, 12 |
| `gender`, `race_ethnicity`, `SES` | Demographics | as recorded (`SES` blank for 1 test essay) |
| `Overall` and six analytic scores | Proficiency | 1 to 5 in steps of 0.5 (average of two raters) |
| `num_words`, `num_sent`, `MTLD`, `TTR` and others | Text statistics computed by the authors | numeric |

- **English learner status is not a column.** Every ELLIPSE writer is an English learner. The counts table records `ell_status = Yes` for all essays.
- **Disability status is not recorded.** The counts table records `Not recorded`.

Essay counts by prompt and grade are in [`results/corpus_essay_counts_summary.md`](../results/corpus_essay_counts_summary.md) and [`results/corpus_essay_counts.csv`](../results/corpus_essay_counts.csv), generated by `make counts`.

### Known issues

1. **Comparisons with PERSUADE are across corpora.** ELLIPSE differs from PERSUADE in prompts (7 of ELLIPSE's 44 prompt names also appear among PERSUADE's 15), grade range, task (independent only), and collection setting (timed state testing). Differences between the corpora are not evidence of an English learner effect on their own; the within-PERSUADE comparison is the primary one.
2. **Grades 9 and 10 are thin**: 32 and 330 essays.
3. **Irregular IDs.** 22 `text_id_kaggle` values are not 12 character hex strings (lengths 8 to 79). They are still unique, so they work as keys, but do not assume a fixed ID format.

## Raw rater-scores file: EXCLUDED FROM THE MAIN ANALYSIS

**Purpose.** Kept only to study why some rated essays were dropped from the final corpus. It must not be used to estimate detector error rates, and it must **never be merged or concatenated with the final corpus**. It lives in its own folder, `data/raw/ellipse_raw_rater_scores/`, and `make counts` skips it (`in_main_analysis: false` in the manifest).

**What it is.** All 8,890 essays rated during corpus construction, with each rater's individual scores. The README says many were dropped "because they were found to not be reliable at the text or rater level."

| Field | Meaning |
|---|---|
| `Filename` | Original file name (8,880 distinct values: 10 names repeat) |
| `text_id_kaggle` | Blank for 2,408 rows; filled for the rest (6,482 distinct IDs) |
| `Text` | Essay text, never displayed or committed |
| `Rater_1`, `Rater_2` | Anonymized rater IDs (27 raters in total) |
| `Overall_k`, `Cohesion_k`, ... `Conventions_k` (k = 1, 2) | Each rater's integer scores, 0 to 5 |
| `Identifying_Info_1`, `Identifying_Info_2` | Rater flag: essay contains identifying information |

**Observations for the dropped-essay study** (from counts only, no merge):

- The 6,482 filled-in `text_id_kaggle` values equal the size of the final corpus, and the 2,408 blank values equal 8,890 minus 6,482. A blank `text_id_kaggle` is therefore likely to mark a dropped essay. This should be confirmed, not assumed.
- 31 essays have an Overall score of 0 from at least one rater. 0 is not a valid score in the final corpus (scale 1 to 5).
- The file has no prompt, grade or demographic fields.

**Privacy.** Raters flagged **188 essays as containing identifying information** (21 flagged by both raters). Treat this file with extra care: never display essay text from it, even in local notebooks, and keep it out of anything shared.

## How to obtain

```
make data          # downloads from GitHub at the pinned commit, verifies SHA-256, extracts the zips
```

The zip passwords are published in the source README (https://github.com/scrosseye/ELLIPSE-Corpus#readme). They are not stored in this repo. Set `ELLIPSE_TEST_ZIP_PASSWORD` and `ELLIPSE_RAW_ZIP_PASSWORD` in the environment or in an untracked `.env` file (see `.env.example`).

**Manual fallback:** download the three files from the repo at the pinned commit, save them into `data/raw/ellipse/` (train and test) and `data/raw/ellipse_raw_rater_scores/` (raw rater scores), then run `make data-verify`. That checks each file's size and SHA-256 before extracting.
